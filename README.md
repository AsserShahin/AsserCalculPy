# AsserCalculPy
This repository is cross-platform cuz python is cross-platform
# Source code
To use it open your terminal and go to my repo source code directory and then type
```
python3 main.py
```
Or
```
python main.py
```
# Installation
To install it go to my releases tab and download the .deb file but this is only for linux debian flavours and install it by
```
sudo apt install ./assercalculpy.deb
```
And then open it on your app menu or run it by
```
assercalculpy
```
And enjoy!
